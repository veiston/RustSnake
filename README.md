# Rust Snake

A teeny weeny Snake game built in Rust with [Bevy](https://bevyengine.org/).

## Requirements

- Rust & cargo installed (see [Rust-lang.org](https://rust-lang.org/tools/install/))
- An OS supported by Bevy (Windows, macOS, or Linux)

## Run

```sh
cargo run
```

## Controls

- Arrow keys
- Eat the `0` to grow
